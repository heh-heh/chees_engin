# chees_engin

C++ 공부를 목적으로 만드는 체스 엔진 프로젝트입니다.

## 프로젝트 방향

C++ 공부를 목적으로 직접 만드는 체스 엔진입니다. 현재는 터미널에서 게임을 진행할 수 있는 프로토타입을 만들고 있으며, 이후 보드 화면과 게임 규칙을 다듬어 실제로 플레이할 수 있는 수준까지 발전시키는 것을 목표로 합니다.

## 현재 구현

- 8 x 8 체스판 초기 상태 출력
- 체스 기물별 기본 이동 형태 검사
	- 폰
	- 나이트
	- 비숍
	- 룩
	- 퀸
	- 킹
- 이동 가능한 좌표인지 체스판 범위 검사
- 기물의 현재 위치와 이동 횟수 관리
- 룩, 비숍, 퀸 등의 이동 경로를 연결 리스트에 저장
- `std::setw`를 사용한 보드 출력 정렬
- 게임 시작 시 32개 기물 생성
- 현재 턴 수와 턴 색상 관리
- 현재 턴의 기물만 선택 가능
- 기물 선택과 목적지 입력을 분리
- 선택한 기물을 ANSI 터미널 색상으로 강조
- 턴이 진행되는 동안 0.1초 단위로 경과 시간 표시
- 이동 성공 시 보드 위치 갱신

현재 보드는 숫자와 ANSI 색상으로 출력되는 초기 화면입니다. 터미널에서 기본적인 이동 흐름을 확인하는 단계이며, 보기 좋은 보드와 완전한 체스 규칙은 앞으로 추가할 예정입니다.

## 디렉터리 구조

```text
src/
├── main.cpp       # 프로그램 시작점
├── game.cpp       # 게임 진행, 입력, 화면 갱신
├── bord.cpp       # 체스판 상태와 보드 출력
├── pieces.cpp     # 기물별 이동 규칙
├── vector.cpp     # 좌표 자료형
├── linked_list.cpp # 이동 경로 저장용 연결 리스트
└── Director.cpp   # 턴, 색상, 이동, 시간 제어
```

## 자료형

좌표는 사용자가 만든 `vector` 타입으로 표현합니다.

```cpp
vector position{3, 4};
```

`x`와 `y`의 범위는 각각 `0`부터 `7`까지입니다.

기물은 다음 값으로 구분합니다.

```text
color: 1 흰색, -1 검은색
type : 1 폰, 2 나이트, 3 비숍, 4 룩, 5 퀸, 6 킹
```

## 실행 방법

프로젝트 루트에서 다음 명령으로 빌드합니다.

```bash
g++ -std=c++17 -Wall -Wextra -pedantic src/main.cpp -pthread -o chess
./chess
```

현재 입력은 출발 좌표와 목적지 좌표를 두 단계로 받습니다.

```text
선택할 기물의 좌표를 입력하세요(fx fy): 1 0
목적지 좌표를 입력하세요(tx ty): 2 0
```

좌표의 범위는 `0`부터 `7`까지이며, ANSI 커서 제어를 지원하는 터미널에서 실행해야 화면 갱신이 정상적으로 보입니다.

## 기물 사용 예시

```cpp
pieces rook(-1, 4, vector{0, 0});

if (rook.move(0, 5)) {
		rook.path().print();
}
```

이동이 성공하면 기물의 현재 위치가 갱신되고, 이동 중간의 좌표는 `path()`로 확인할 수 있습니다.

개별 소스 파일의 문법만 확인하려면 다음처럼 컴파일합니다.

```bash
g++ -std=c++17 -Wall -Wextra -pedantic -c src/game.cpp -o /tmp/game.o
g++ -std=c++17 -Wall -Wextra -pedantic -c src/bord.cpp -o /tmp/bord.o
```

## 다음 개발 계획

### 1. 보드 화면 개선

- 숫자 대신 체스 기물 기호 또는 문자 출력
- 흑백 칸 색상 적용
- 선택 칸, 이동 가능한 칸, 마지막 이동 칸 강조
- 행과 열 좌표 표시
- 터미널 크기에 맞는 정렬과 화면 깜빡임 개선

### 2. 기본 게임 규칙 완성

- 다른 기물에 의한 이동 경로 차단
- 기물 잡기
- 폰의 대각선 잡기와 프로모션
- 아군 기물이 있는 칸으로 이동 제한
- 이동 후 `Board`와 기물 목록 상태 동기화

### 3. 체스 규칙 추가

- 캐슬링 및 앙파상
- 체크, 체크메이트, 스테일메이트 판정
- 게임 종료 및 재시작

### 4. 구조 정리

- 기물 클래스와 보드 클래스의 헤더 파일 분리
- `.cpp` 직접 include 제거
- 입력, 게임 규칙, 화면 출력 테스트 추가
