# chees_engin

C++ 학습을 목적으로 구현한 터미널 기반 체스 엔진 프로젝트입니다.

## 프로젝트 개요

이 프로젝트는 체스판 상태를 관리하는 보드 계층과, 각 기물의 이동 규칙을 관리하는 기물 계층, 그리고 입력/선택/출력 흐름을 연결하는 게임 루프를 함께 구성한 작은 체스 엔진입니다. 현재 코드는 체스의 기본 판정 흐름을 터미널에서 확인할 수 있는 수준까지 구현해 두었고, 이후에는 체크, 체크메이트, 캐슬링, 승패 판정 등 완전한 체스 규칙을 추가하는 방향으로 확장할 수 있습니다.

## 현재 구현된 기능

- 8 x 8 체스판을 `Board` 객체로 관리하고 출력합니다.
- `vector` 좌표 자료형을 사용해 기물의 위치와 이동 좌표를 표현합니다.
- 기물 객체의 색상과 종류를 관리합니다.
  - `color: 1` = 흰색, `-1` = 검은색
  - `type: 1` = 폰, `2` = 나이트, `3` = 비숍, `4` = 룩, `5` = 퀸, `6` = 킹
- 보드에서 좌표 범위 검사, 아군/적군 판정, 경로 차단 판정, 기물 존재 여부 확인을 수행합니다.
- 기물 이동 검증에서 `can_move_to()`와 `is_publicly_valid_destination()` 흐름을 사용해 이동 후보와 실질적인 이동 가능성을 구분합니다.
- `alive` 상태를 추가하여 잡힌 기물은 보드 조회와 기물 검색에서 제외되도록 처리합니다.
- `Board::remove_piece_at()`와 `Board::move_piece()`를 통해 보드 상태와 기물 객체 상태를 동기화합니다.
- 선택 기물의 이동 가능 위치와 불가능한 좌표에 대해 보드 표시 단계에서 각각 다른 표현을 제공합니다.
- 적군 기물인 경우 잡기 동작을 수행하고, 잡힌 위치의 보드 상태를 정리한 뒤 선택 기물의 좌표를 실제 도착 좌표로 이동시킵니다.
- 기물 객체의 이동 규칙, 체크, 메이트, 경로 계산, 좌표 판정, 생존 여부 관리 등에 주석을 보강해 이후 수정이 쉬운 구조로 정리했습니다.

## 파일 구조

```text
src/
├── main.cpp        # 프로그램 시작점
├── game.cpp        # 입력 처리, 선택 기물 관리, 게임 루프
├── bord.cpp        # 보드 출력, 기물 삭제, 좌표 판정, 경로/공격 판정
├── pieces.cpp      # 기물 규칙, 이동 검증, 체크/메이트 뼈대, 생존 상태 관리
├── vector.cpp      # 좌표 타입 구현
├── linked_list.cpp # 이동 경로 저장 구조
└── Director.cpp    # 턴 관리, 색상 관리, 이동 제어
```

## 실행 방법

프로젝트 루트에서 다음 명령으로 빌드합니다.

```bash
cd /workspaces/chees_engin
g++ -std=c++17 -Wall -Wextra -pedantic src/main.cpp -pthread -o chess
./chess
```

기본 입력 흐름은 다음과 같습니다.

```text
선택할 기물의 좌표를 입력하세요(fx fy): 1 0
목적지 좌표를 입력하세요(tx ty): 2 0
```

좌표는 체스판 범위인 `0`부터 `7`까지 사용하며, ANSI 색상과 터미널 커서 제어가 지원되는 터미널에서 실행하는 것이 가장 자연스럽습니다.

## 현재 개발 상태

구현은 아직 완전한 체스 규칙 엔진이 아니라, 터미널에서 이동 후보와 불가 후보를 보기 쉽게 출력하는 방향으로 정리된 프로토타입 단계입니다. 현재 기준으로는 다음 항목이 핵심 흐름으로 정리되어 있습니다.

- 기물 검색을 `find_piece_at()`처럼 좌표 기반으로 쉽게 처리
- 이동 가능 후보와 이동 불가 후보를 별도 후보 목록으로 구분해 화면에 표시
- 경로 중간의 기물, 아군 기물, 적군 기물, 출발 기물의 존재와 이동 가능성을 각 함수에서 판정
- 잡힌 기물에 대해 `alive = false`를 반영하고 보드 상태에서 비활성화
- 움직이는 기물의 위치를 목적지 좌표까지 실제로 반영

- 경로 공격 판정의 정밀화

- 기물 클래스를 헤더 기반 분리로 관리

- 입력 좌표, 유효 이동, 비유효 이동, 마지막 이동 위치를 함께 표시
- 체스 기물 기호 기반 출력으로 가독성 향상
- 보드 셀의 색상과 후보 위치 시각화 강화
